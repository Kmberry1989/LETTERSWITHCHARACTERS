# Five in Six guess dictionary

The generated `five-in-six-guesses.ts` validation list combines the app's curated answer pool with the Wordle allowed-guesses and answer lists published in `dgaff/wordle`.

- Source: https://github.com/dgaff/wordle
- Source files: `wordle-allowed-guesses.txt` and `wordle-answers-alphabetical.txt`
- Retrieved: 2026-10-05
- License: Apache License 2.0, reproduced at `THIRD_PARTY_LICENSES/dgaff-wordle-APACHE-2.0.txt`

The generated list is used only to accept guesses. The smaller `FIVE_IN_SIX_WORDS` list remains the answer pool so solutions stay familiar and fair.
